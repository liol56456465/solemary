# Security policy

## Reporting a vulnerability

If you find a security problem in Mewvo (the bot, the web dashboard or the website), please tell
us privately first:

- open a ticket or a modmail in the Mewvo support server: https://discord.gg/7Ckv9Bt577
  (say it is a security report; staff will move it to a private channel), or
- DM the bot, choose "Send to staff", and mark it as a security report.

Please include what you found, how to reproduce it, and what an attacker could do with it. Do not
open a public GitHub issue, do not post details in public channels, and do not access, change or
delete other people's data while testing.

We will confirm we got your report, keep you updated, and credit you if you want.

## Scope and rewards

This is a small, community-run project: there is **no bug bounty** and no paid rewards.

## Supported versions

Only the version currently running (the latest code on the deployed branch) gets fixes.
