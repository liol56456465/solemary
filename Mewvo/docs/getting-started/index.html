Getting started for staff

Who can use what, your first enforcement action, and the commands you’ll use every week.

Who can do what

Everyday commands (help, rank, leaderboard, fun, to-do lists, reports and so on) are open to every member. Anything that moderates, changes settings, posts as the bot, affects other members or moves currency needs the Administrator role. The check runs every time a command or button is used, not only when it is first opened.

Members without Administrator who try a staff command are told so and pointed to the channel where they can request a role.

Your first action

  1. Run /enforcements user:@member. The panel shows the member’s account age, time in the server, counted warnings, ladder level, any active punishment and their last cases. Only you can see it.
  2. Press the action: Ban, Kick, Mute or Warn (or Unban, Unmute, Remove warn when they apply).
  3. Choose a prebuilt reason or Custom… and type one.
  4. For a mute, give a duration such as 30m, 24h, 7d or 1mo. For a ban, the same, or leave it blank for a permanent ban.
  5. Check the summary and press Confirm.

The member gets a DM before a kick or ban happens. If the DM can’t be delivered, the action still goes ahead and you are told. The panel expires after 15 minutes; run the command again if it does.

Commands you’ll use

/background
A member’s full case history.
/case
Search cases, edit a reason or duration, void a mistaken case, see its history, attach evidence.
/appeals
Accept or deny an appeal by case code, with a note.
/test
Sends you the exact DM a member would get. Nothing is done to anyone.
/staff
Staff activity and stats.
Warn for this message
Right-click a message, then Apps: warns the author with the message attached.

Limits that protect the server

Mewvo refuses to act on the server owner, the bot, yourself, or anyone whose highest role is equal to or above yours. If one moderator bans or kicks more than 5 members in 10 minutes, they are blocked for an hour and the owner is told.
