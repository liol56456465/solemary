General

/help
Displays the help menu with all available commands
/ping
Checks the bot's latency and API speed
/stats
View bot statistics
/support
Get link to the support server
/uptime
Check how long the bot has been online

Community

/apply list
List available applications to apply for
/apply status
Check the status of your application
/apply submit
Submit an application for a role
/suggest new
Post a suggestion members can vote on
/tag list
List the tags
/tag show
Post a tag in this channel

Leveling

/leaderboard
Shows the server's level leaderboard
/rank
Check your or another user's rank and level

Fun

/count leaderboard
Show the counting game leaderboard
/count status
View current counting game status
/fun fight
Start a simulated 1v1 text battle
/fun flip
Flip a coin
/fun roll
Roll dice (e.g. 2d20, 1d6 + 5)

Birthdays

/birthday info
View birthday information
/birthday list
List all birthdays in the server
/birthday next
Show upcoming birthdays
/birthday remove
Remove your birthday
/birthday set
Set your birthday

Utility

/avatar
Display a user's avatar image
/firstmsg
Get a link to the first message in this channel
/report file
Report a user to the server moderation team.
/serverinfo
Get detailed information about the server
/todo add
Add a task to your to-do list
/todo complete
Mark a task as complete
/todo list
View your to-do list
/todo remove
Remove a task from your to-do list
/todo share add
Add a member to a shared list
/todo share addtask
Add a task to a shared to-do list
/todo share create
Create a new shared to-do list
/todo share remove
Remove a task from a shared to-do list
/todo share view
View a shared to-do list
/userinfo
Get detailed information about a user
/weather
Get real-time weather information for a location
/wipedata
Delete all your personal data from the bot (irreversible)

Tools

/tools baseconvert
Convert numbers between bases
/tools calculate
Evaluate a math expression
/tools generatepassword
Generate a strong random password
/tools hexcolor
Random hex color with preview
/tools time
Current time in different timezones
/tools unixtime
Current Unix timestamp

Search

/search define
Look up a word definition
/search google
Search Google

Verification

/verify
Verify yourself and gain access to the server

Tickets

/canned list Ticket staff
Show all saved answers
/canned send Ticket staff
Post a saved answer in this channel
/claim Ticket staff
Claims an open ticket, assigning it to you.
/close Ticket staff or the ticket opener
Closes the current ticket.
/modmail close Ticket staff
Close this modmail conversation
/priority Ticket staff
Sets the priority level for the current support ticket.

Right-click menus

Report message
Right-click a message → Apps → Report message
