Last updated 29 October 2026.

The short rules for using Mewvo. By using the bot you accept them.

Using the bot

  • Follow Discord’s Terms of Service and Community Guidelines, and the rules of the server you are in.
  • Don’t use Mewvo to harass anyone, to spam, or to get around a punishment.
  • Don’t try to break, overload or misuse the bot, this website or the dashboard.

Moderation decisions

Mewvo carries out what a server’s staff decide. Warnings, mutes, kicks and bans are decisions of that server’s staff team; the automatic steps of the warning ladder follow the rules that server has set.

Appeals

If a punishment can be appealed, the DM about it says how. One appeal per case can be open at a time, and staff decide and tell you the result. Some punishments cannot be appealed; the DM says so.

Being blocked

The bot’s owner can block an account or a server from using Mewvo, for example for abusing it.

No warranty

Mewvo is provided as it is, for free, without any promise that it is always available, free of errors or fit for a particular purpose. It can change, pause or stop at any time.

Your data

See the privacy page for what Mewvo stores and how to delete it.

Changes

These terms can change; the date above shows the latest version. Questions: ask in the support server.
